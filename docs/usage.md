# Використання проєкту

## Запуск агента у VS Code

1. Відкрийте кореневу папку репозиторію у VS Code.
2. Відкрийте **Copilot Chat**.
3. Виберіть агента **`build-engineer`**.
4. У Copilot Chat виконайте команду:

   ```text
   /project-init
   ```

5. Після завершення повного налаштування запустіть фінальну перевірку:

   ```text
   /check
   ```

## Локальна збірка та перевірка

На Linux або macOS із кореня репозиторію виконайте:

```bash
./ci.sh
```

На Windows із кореня репозиторію виконайте:

```bat
ci.bat
```

Скрипти встановлюють залежності, запускають тести та створюють каталог
`dist/`.

## Запуск Hello World

Після збірки виконайте:

```bash
node dist/hello.js
```

Очікуваний результат:

```text
Hello, World!
```

## Запуск тестів

Для окремого запуску Jest-тестів виконайте:

```bash
npm test
```
